# 📚 BookShop Website

A responsive BookShop website developed using **HTML, CSS, and JavaScript**.

### 🌐 Live Demo
[🚀 View Live Website](https://shonali280.github.io/BookShop/)

## ✨ Features

- 📚 Clean and responsive BookShop interface
- 🔐 User Login page
- 📝 User Registration page
- 📱 Responsive web design
- 🎨 Modern and simple user interface
- ⚡ JavaScript-based interactions

## 📂 Project Structure

- `index.html` - Main BookShop page
- `login.html` - User login page
- `register.html` - User registration page
- `style.css` - Main stylesheet
- `login_re.css` - Login and registration styles
- `script.js` - JavaScript functionality
- `resources.zip` - Project resources

## 🚀 How to Run

1. Download or clone this repository.
2. Extract the project files if necessary.
3. Open `index.html` in a web browser.
4. Explore the BookShop website.

This project was created to practice and demonstrate front-end web development skills using HTML, CSS, and JavaScript.
